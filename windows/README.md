# Screen Annex for Windows

从 [GitHub Releases](https://github.com/farceli/screen-annex/releases) 下载 `Screen-Annex-windows-x64.zip`。解压整个目录后，双击 `ScreenAnnex.exe`。程序自带 .NET、Windows App SDK、ADB 和 scrcpy。

在手机上开启 USB 调试并确认授权，再从设备列表选择「投屏」。如 Windows 未识别手机的调试接口，请按机型安装 [USB 驱动](https://developer.android.com/studio/run/oem-usb)。无线调试按手机显示的配对地址及连接地址操作。
