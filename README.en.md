# Screen Annex

[简体中文](README.md)

## Overview

Screen Annex is a desktop app for mirroring and controlling Android phones on macOS and Windows. Each device gets its own window, with keyboard and mouse control, wireless connections, drag-and-drop file transfers, and APK installation.

Preview builds are available on [GitHub Releases](https://github.com/farceli/screen-annex/releases).
