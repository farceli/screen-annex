# Screen Annex

[English](README.en.md)

## 介绍

Screen Annex 是一款在 macOS 和 Windows 上投屏并操控 Android 手机的桌面应用。每台设备有独立窗口，支持键鼠控制、无线连接、拖放传文件和 APK 安装。

预览版可在 [GitHub Releases](https://github.com/farceli/screen-annex/releases) 下载。
