Screen Annex 的首个 Android 桌面预览版。ADB 和 scrcpy 随软件提供。

- **Apple 芯片 Mac** 下载 `Screen-Annex-macos-arm64.dmg`。
- **Intel Mac** 下载 `Screen-Annex-macos-x64.dmg`。
- **Windows x64** 下载 `Screen-Annex-windows-x64.zip`。解压整个目录后运行 `ScreenAnnex.exe`。

macOS 使用临时签名。首次打开若被系统拦截，确认来源后可在「系统设置 → 隐私与安全性」为此 App 选择「仍要打开」。[Apple 支持说明](https://support.apple.com/102445)

首次连接需在 Android 手机上开启调试并授权。无线调试需要按手机显示的地址完成配对和连接。本次预览面向 Android，Windows 真机体验仍在验证中。

附件包含 `SHA256SUMS.txt` 和 ADB 对应源码。只使用软件时，下载自己平台的安装包即可。
