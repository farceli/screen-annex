## 安装

- **macOS 14+**（`arm64` 为 Apple 芯片，`x64` 为 Intel）打开 DMG，将 App 拖入「应用程序」。临时签名版若被拦截，确认来源后可选择「仍要打开」。[Apple 支持说明](https://support.apple.com/102445)
- **Windows x64** 解压 ZIP，运行 `ScreenAnnex.exe`。

首次连接需在 Android 手机上开启调试并授权。第三方对应源码与重新链接材料见同页附件 `Screen-Annex-corresponding-source.zip`。
